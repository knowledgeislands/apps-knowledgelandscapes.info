# Knowledge Landscapes

The holding page for [knowledgelandscapes.info](https://knowledgelandscapes.info): Knowledge Landscapes, part of [Knowledge Islands](https://knowledgeislands.info), is coming soon. It is a Knowledge Islands microsite, and for now it carries the domain and that one line.

## Working on the site

```bash
bun install
bun run ki:site:dev    # Tailwind watch + Eleventy serve on http://localhost:3000
bun run ki:site:build  # compile the site to apps/site/dist/
bun run test
```

Deployment is described in [the Cloudflare guide](docs/guides/developer/cloudflare.md).
